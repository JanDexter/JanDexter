## Not Public

Some of the work I'm proudest of isn't open, usually because it carries client
data, a collaborator's rights, or research that isn't mine alone to publish.
Short version of what's behind that line:

- **Pleks** — physical-therapy platform. On-device pose estimation gives patients
  real-time form feedback on home exercises; a voice copilot drafts clinical notes
  from session audio. Built with a licensed physical therapist, in four languages.
  Nuxt 3, TensorFlow MoveNet, Supabase, AWS Lambda and Bedrock.
- **papyr** — local-first desktop workspace for researchers: PDF library, notes,
  BibTeX and a full LaTeX editor over embedded SQLite, with collaborative sync on
  Cloudflare Durable Objects. Tauri, Rust and React.
- **Dengue early-warning system** — eight-week incidence forecasting for a
  Philippine region, built on OCR-extracted health bulletins fused with NASA POWER
  climate reanalysis. Python, LightGBM, Nuxt 3.
- **CO-Z Reservation** — co-workspace booking platform. Laravel 11, Inertia, Vue 3,
  MySQL, with 2FA and Google OAuth.

Happy to walk through any of these, including the code, in a conversation.
